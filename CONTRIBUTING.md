# Contributing to Glitch SEO Ops Engine

1. Fork and create a feature branch (`git checkout -b feature/seo-enhancement`).
2. Follow Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`).
3. Ensure all tests pass: `node packages/testing/run_all_tests.js`.
4. Ensure TypeScript compiles: `pnpm typecheck`.
